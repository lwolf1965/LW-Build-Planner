# LW Build Planner

[English](README.md) | Русский

Клиентский плагин для Space Engineers 2: выберите блоки в меню G, посмотрите, какие компоненты для них нужны и что уже есть в хранилище, и закажите недостающее у своих станков одним нажатием.

Статус: **0.1.1.0, тестовая сборка** (0.1.0.1 есть в PluginHub-SE2). Только одиночная игра. Работает вместе с [LW Cargo Manager](https://github.com/lwolf1965/LW-Cargo-Manager), который собирает готовые компоненты в контейнеры `[Parts]`.

## Что умеет
- **Выбор блоков**: выберите вариант и размер блока в меню G и нажмите `+`, чтобы добавить его в список постройки (Shift / Ctrl — шаг больше).
- **Целые чертежи**: на вкладке «Чертежи» терминала выберите чертёж и нажмите `+`: все его блоки (включая броню) попадают в список как один проект-чертёж. На экране игры «Детали чертежа» появляется блок Build Planner: сколько руды стоит весь чертёж, хватает ли запасов (иначе — какой руды не хватает) и кнопка **«Добавить в Build Planner»**.
- **Окно планировщика**: список постройки, компоненты (нужно, в хранилище, в заказе, не хватает), проблемы, текущие заказы.
- **«Заказать всё»** или **«Дозаказать»**: только целые блоки (никогда половина блока): сначала склад покрывает блоки, остальное делается начиная с самых маленьких, а при нехватке руды **«Дозаказать»** делает блоки, на которые она есть, остальные ждут. Чертёж, на который не хватает руды, ждёт целиком (полкорабля поплывёт), если не нажать **«Заказать, на что хватает»** в его строке. Компоненты ставятся партиями в очередь свободных станков; станок, закончивший партию, получает следующую. Стройте столько станков, сколько можете: чем больше станков, тем быстрее большая постройка. Подкомпоненты станки игры сами запрашивают у меньших станков.
- **Точное изготовление**: компонент, который входит в другой заказанный компонент (на любой глубине: Steel Plate в Heavy-Duty Plate), делается после него, поэтому ни один станок не забирает компоненты, предназначенные для блоков; сложные компоненты идут первыми. Раздел «Заказы» показывает, чего ждёт станок («ждёт руду: Iron», «ждёт Steel Plate», «следующим: после Heavy-Duty Plate»).
- **Раунды**: следующие раунды начатого чертежа (**«Заказать, на что хватает»**) делаются только из руды: добыли — нажали, добыли — нажали, пока корабль не готов.
- **Сохраняется с миром**: список постройки и идущие заказы записываются при каждом сохранении и продолжаются после загрузки; компоненты, потерянные из очередей станков, делаются заново. Загрузка более старого сохранения открывает окно: оставить список или остановить заказы и очистить его.
- **Проверки** перед заказом: нехватка руды, нет станка нужного типа, нет связи конвейера, нет хранилища, не хватает места в хранилище (заказ блокируется; предупреждение, если занято больше 80 % свободного места). Неработающие станки (не достроены, повреждены, без питания) называются в замечаниях.
- **Следит за заказами**: сообщает, когда все станки одного типа заняты, когда заказ не продвигается и когда всё готово. Затем заказанные блоки убираются из списка и заказы очищаются, чтобы готовую постройку случайно не заказать дважды.
- Стоимость блоков и рецепты читаются из игры при каждой загрузке мира, поэтому моды и обновления игры учитываются.
- **На 13 языках игры**: окно, уведомления и тексты проблем (`ClientPlugin/Policy/TrTable.cs`; исправления приветствуются).

## Как пользоваться
1. Откройте меню G, выберите блок (группу, вариант, размер) и нажмите `+`. Повторите для каждого блока, который хотите построить.
2. Нажмите **Ctrl+N**, чтобы открыть окно планировщика. В разделе «Компоненты» видно, чего не хватает; проблемы (руда, станки, конвейеры, место в хранилище) показываются до заказа.
3. Нажмите **«Дозаказать»** (только то, чего нет) или **«Заказать всё»** (всё заново). Для чертежа, которому не хватает руды, нажмите **«Заказать, на что хватает (N)»** в его заголовке; после добычи нажмите снова.
4. Блоки уходят из списка, как только все их компоненты отданы станкам. Следите за разделом «Заказы»; когда приходит последний компонент, появляется зелёное уведомление.

Руководство: [Docs/UserManual.ru.md](Docs/UserManual.ru.md) ([English](Docs/UserManual.md)). Изменения: [CHANGELOG.md](CHANGELOG.md) (на английском).

## Клавиши
| Клавиша | Действие |
|---|---|
| `+` (и `+` на цифровой клавиатуре) | добавить выбранный блок; Shift, Ctrl и Alt — шаг больше |
| Ctrl+N | открыть окно планировщика (в любом месте мира) |

Обе клавиши, шаги и настройки заказов можно изменить в настройках (кнопка настроек в Pulsar или **«Настройки»** в окне планировщика).

Всё остальное (убрать, очистить, заказать) — кнопки в окне, поэтому случайное нажатие клавиши не убирает блоки из списка и не запускает станки.

## Установка
**Игрокам:** плагин есть в PluginHub: откройте список плагинов в Pulsar, включите **LW Build Planner** и перезапустите игру.

**Сборка для разработки:**
1. Скопируйте `Directory.Build.props.user.example` в `Directory.Build.props.user`, укажите `Game2` (папка с `SpaceEngineers2.exe`) и `Pulsar` (например `$(APPDATA)\Pulsar`).
2. `dotnet build`: DLL копируется в `<Pulsar>\Modern\Local`.
3. Запустите игру через Pulsar и включите **LwBuildPlanner** в списке плагинов.

`dotnet run --project tests` запускает проверки логики (должно закончиться `ALL PASSED`).
`dotnet build -c Release` дополнительно копирует DLL в `Release\`.

## Ограничения
- Компоненты, которые уже в станке, пока нельзя отменить из планировщика.
- Заказанные блоки уходят из списка, когда их компоненты отданы станкам (настройка **«Сохранять список после выполнения»** оставляет их для следующего заказа).
- Список постройки сохраняется вместе с миром: записывается при каждом сохранении игры (и при автосохранении), поэтому после выхода без сохранения или вылета он соответствует сохранению. Идущие заказы тоже сохраняются и продолжаются после загрузки. Файлы относятся к последнему сохранению; загрузка более старого открывает окно.
- Заказы идут станкам одной сетки (той, где больше всего станков). Хранилища на других сетках учитываются, если станки достают до них по конвейеру.
- То, что вы несёте с собой, не учитывается, только хранилища в сети конвейера.
- `+` в меню G читается через вызов Windows; Ctrl+N использует ввод самой игры и работает везде.
